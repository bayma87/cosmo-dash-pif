# 🚀 Cosmo Dash

Cosmo Dash é um jogo de sobrevivência espacial desenvolvido em linguagem C, executado em linha de comando. O jogador controla uma nave e precisa desviar de asteroides para sobreviver pelo maior tempo possível, acumular pontos e alcançar novos recordes.

## 🎮 Objetivo do jogo

Evitar colisões com asteroides, preservar as vidas disponíveis e obter a maior pontuação possível. Ao longo da partida, a dificuldade aumenta, tornando a sobrevivência cada vez mais desafiadora.

## ⚙️ Funcionalidades

* Controle e movimentação da nave.
* Geração aleatória de asteroides.
* Detecção de colisões.
* Sistema de vidas e pontuação.
* Dificuldade progressiva.
* Animações e movimentação contínua no terminal.
* Registro de recordes em arquivo.

## 🛠️ Tecnologias

* **Linguagem:** C
* **Ambiente de execução:** Terminal/linha de comando
* **Armazenamento:** Arquivos locais para registro de recordes


## 🕹️ Como jogar

1. Execute o jogo no terminal.
2. Utilize os controles definidos na implementação para movimentar a nave.
3. Desvie dos asteroides e evite colisões.
4. Preserve suas vidas e sobreviva o máximo possível.
5. Tente superar sua melhor pontuação.

## 📚 Conceitos aplicados

O desenvolvimento do Cosmo Dash permite aplicar conceitos fundamentais da programação em C, incluindo estruturas de decisão e repetição, funções, geração de valores aleatórios, detecção de colisões e manipulação de arquivos.
